# 🥔 감자 키우기

프린세스 메이커 오마주 육성 시뮬레이션 게임.

## 게임 방법

### 기본 흐름
1. `/game` 으로 접속
2. 매일 **오늘 체력(♥×10)** 을 소모해 행동 선택
3. **"다음 날로 →"** 버튼으로 하루 마감 (체력 충전)
4. 30일 후 달성한 스탯에 따라 엔딩 결정

### 행동 종류

| 행동 | 체력 소모 | 수입 | 주요 효과 |
|------|-----------|------|-----------|
| **고강도 알바** | ♥×4 | +30원 | 스트레스 많이 오름 |
| **저강도 알바** | ♥×3 | +25원 | 스트레스 적게 오름 |
| **교육** | ♥×2 | -20원 | 지식/기품/감수성/도덕성 성장 |
| **휴식** | ♥×1 | 없음 | 스트레스 해소 |

### 알바 종류

| 종류 | 구분 | 주요 스탯 변화 |
|------|------|---------------|
| 야간 경비 | 고강도 | 매력↑, 스트레스↑↑ |
| 주점 바텐더 | 고강도 | 매력↑↑, 도덕성↓, 기품↓ |
| 농장 일꾼 | 고강도 | 체력↑, 도덕성↑ |
| 광산 노동 | 고강도 | 체력↑↑, 기품↓ |
| 카페 알바 | 저강도 | 매력↑, 감수성↑ |
| 아침 조깅 알바 | 저강도 | 체력↑, 멘탈↑, 스트레스↓ |

### 교육 종류

| 종류 | 주요 스탯 변화 |
|------|---------------|
| 도서관 공부 | 지능↑↑ |
| 예절 교육 | 도덕성↑↑, 기품↑ (불량아 탈출 가능) |
| 예술 교육 | 감수성↑↑, 기품↑ (비 이벤트 20% 확률) |
| 성당 | 도덕성↑, 멘탈↑, 스트레스↓ |

### 휴식 종류

산책 선택 시 **채팅창에서 목적지를 선택**할 수 있어요.

| 종류 | 목적지 선택 | 효과 |
|------|------------|------|
| 집에서 쉬기 | - | 스트레스↓↓, 멘탈↑ |
| 산책하기 | 공원 / 상점 / 마을 광장 | 목적지에 따라 다름 |
| 거리 공연 | - | 감수성↑, 스트레스↓ |

## 상점 아이템

산책 → 상점 선택 시 구매 가능

| 아이템 | 가격 | 효과 |
|--------|------|------|
| 🍶 독한 술 | 400원 | 매력+80, 도덕성-15, 스트레스-10 |
| 💎 매혹의 목걸이 | 400원 | 매력+60, 기품+25 |
| 📕 지식의 두꺼운 책 | 200원 | 지능+70 |
| 🧪 힐링 포션 | 150원 | 스트레스-50, 멘탈+20 |
| 💊 헬스 보충제 | 180원 | 체력+50 |

## 스탯 시스템

| 스탯 | 범위 | 설명 |
|------|------|------|
| 체력 | 0~999 | 농장·광산·운동으로 성장 |
| 지능 | 0~999 | 도서관 공부로 성장 |
| 기품 | 0~999 | 예절·예술 교육으로 성장 |
| 매력 | 0~999 | 알바·상점 아이템으로 성장 |
| 감수성 | 0~999 | 예술·거리공연으로 성장 |
| 도덕성 | 0~100 | 0이 되면 위험 |
| 멘탈 | 0~100 | 스트레스 누적 시 깎임 |
| 스트레스 | 0~100 | 80 이상이면 매일 멘탈 감소 |

## 이벤트

### 고구마 이벤트 🍠
- **발동 조건:** 산책 → 공원, 20% 확률 (최초 1회)
- **효과:** 불량아 모드 돌입, 도덕성↓, 매일 도덕성 서서히 감소
- **탈출:** 예절 교육 반복 → 도덕성이 35 이상이 되면 복귀

### 비 오는 날 이벤트 🌧️
- **발동 조건:** 예술 교육 중 20% 확률
- **효과:** 감수성 추가 보너스

### 기대기 이벤트 💕
- **발동 조건:** 산책 → 공원, 5% 확률
- **효과:** 감수성↑, 멘탈↑ / 매쉬드포테이토 엔딩 조건

### 바스락 이벤트 🎵
- **발동 조건:** 거리 공연 중 15% 확률
- **효과:** 감수성 추가 보너스
